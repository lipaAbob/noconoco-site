# noconoco — Portfolio Website (Production Package)

## Folder Structure
Place your Google Drive files into the two folders inside `public/assets/`:

- `public/assets/logos/`
  - `ibmlogo.png`, `pradalogo.png`, `cliniquelogo.png`, `triumphlogo.png`, `kenneth-colelogo.png`, `durexlogo.png`, `cenitlogo.png`, `eventmatchlogo.png`, `extracitylogo.png`, `goldpasslogo.png`, `mymodelogo.png`
- `public/assets/images/`
  - Drawer 01: `cenit1.png`..`cenit4.png`, `ibm1.jpg`..`ibm6.jpg`
  - Drawer 02: `extracity1.png`, `eventmatch1.png`
  - Drawer 03: `trailergoldpass.mp4`, `mymodeflow.jpg`
  - Drawer 04: `f1.jpg`..`f10.jpg`, `cross1.jpg`, `cross2.jpg`, `mag1.jpg`..`mag5.jpg`

## Deploy to GitHub + Vercel (0 EUR)
1. Create a new repository on GitHub (e.g. `noconoco-site`).
2. Upload all files from this folder (including `public/assets/logos` and `public/assets/images`).
3. Import the repository in Vercel (`vercel.com`), keep default Vite settings, and click **Deploy**.
4. Connect your custom domain `noconoco.es` in Vercel -> Project Settings -> Domains.
